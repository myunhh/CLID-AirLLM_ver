# Human stage gate

Before mutation, present:

1. Task class and why.
2. Graph evidence and affected communities/files.
3. Proposed stages, each with output and verification.
4. Agents and ownership boundaries.
5. Budget and hard stops.
6. Recommended stage selection.

Ask: `어느 단계까지 진행할까요?`

Offer concise choices appropriate to the task, normally:

- `A. 조사·계획만`
- `B. 구현과 로컬 검증까지 (추천)`
- `C. 통합 검증 및 전달물까지`

Do not include push, merge, publish, paid actions, credential changes, or third-party mutations inside an implied choice. Ask separately when they become relevant.
